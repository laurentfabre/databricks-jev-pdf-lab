# Public research snapshot

Keep the frozen benchmark schema, instructions, Precision v2.1, and citations.
Structural checks and typed judgments never prove semantic correctness.
Keep missing evidence distinct from a wrong answer. Preserve raw outputs and
execution handles privately; do not repeat inference after an unknown outcome.

Only synthetic offline tests may run on the local machine or GitHub Actions.
Document experiments need an explicitly approved Databricks workspace/profile.
No public document data or hosted inference credential is included. Public
publication does not authorize source-bearing requests to any service.

Record decisions and failures in JOURNAL.md without source contents or private
infrastructure details. Never add PDFs, original excerpts, extraction outputs,
raw request logs, credentials, or private receipts. Review the explicit public
file manifest and run scripts/check_publication.py before publishing changes.

Consult the current TypeSafe and Databricks primary documentation before
changing their integration contracts. Do not claim full reproducibility from
the aggregate result tables or accept code-only checks as quality evaluation.
